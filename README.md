# Бот для розыгрышей по активности

Telegram-бот (aiogram 3, SQLite, long polling). Считает сообщения участников в одном чате за период, по окончании периода выбирает победителя среди самых активных (шанс пропорционален числу сообщений), объявляет в чате с фото и текстом и закрепляет итоги. Статистика после розыгрыша обнуляется. Всё настраивается в самом боте: `/admin`.

## Подготовка
1. Создай бота в [@BotFather](https://t.me/BotFather), возьми токен.
2. В @BotFather: `/mybots` → бот → Bot Settings → Group Privacy → **Turn off** (иначе бот не видит обычные сообщения).
3. Добавь бота в чат **админом с правом «Закреплять сообщения»**.

## Запуск на хостинге (Linux, Python 3.10+)
```bash
git clone https://github.com/sakurartro/fawer1_order bot && cd bot
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env && nano .env      # BOT_TOKEN, ADMIN_PASSWORD, при желании BOT_TZ
.venv/bin/python main.py               # проверка; Ctrl+C
```

Постоянная работа через systemd, `/etc/systemd/system/giveaway-bot.service` (поправь пути и пользователя):
```ini
[Unit]
Description=Giveaway bot
After=network-online.target

[Service]
User=bot
WorkingDirectory=/home/bot/bot
ExecStart=/home/bot/bot/.venv/bin/python main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl enable --now giveaway-bot
journalctl -u giveaway-bot -f          # логи
```

Запускай **ровно один экземпляр** на токен: два параллельных бота будут мешать друг другу.

## Первая настройка
1. В личке с ботом: `/reg_admin` → пароль из `.env` → выбери, показывать ли твой @username в постах (для выдачи призов). Админов может быть несколько, у каждого свой выбор.
2. В нужном чате отправь `/bind` (только админ бота).
3. В личке `/admin`: число победителей, размер топа, срок (повтор каждые N дней или конкретные даты), текст и фото поста (`{winner}` заменяется на победителя), предпросмотр, «Разыграть сейчас», история.

## Правила учёта
- Считаются текст и подписи к медиа от 5 символов, не чаще раза в 10 секунд от одного человека (`config.py`: `MIN_LEN`, `COOLDOWN`).
- Не считаются: команды, боты, админы чата, админы бота, анонимные сообщения.
- Победитель выбирается из топа (по умолчанию 10) с весом по числу сообщений.

## Что важно знать
- Данные лежат в `bot.db` (путь меняется переменной `DB_PATH`). Копируй файл для резервной копии.
- Если не удалось объявить итоги в чате (нет прав, чат не привязан), админы получают личное предупреждение с победителями.
- Если чат стал супергруппой, бот сам обновит привязку.
- Пароль админа задай длинным и случайным: по нему любой может стать админом бота.
